California College of the Arts 交互设计背景，2026 年起在观远数据实习，从事 ChatBI / Data Agent 产品线的体验设计。

洞察 Agent · 移动端

2026.08 · AI Agent 对话体验 · 已上线

洞察 Agent 是企业 BI 平台中的深度分析智能体。业务人员以一句话提出经营问题，智能体自行查阅多张仪表板，数分钟后交付结论或分析报告。本项目设计的是提问者使用的对话界面。

ChatBI 治理台

2026.07 · 企业 Agent 配置管理 · 开发中

本项目是 ChatBI 的智能体管理后台。管理员（懂业务、会写查询，常由业务小组长或数据分析师担任）在这里搭建和维护智能体，业务人员通过自然语言向智能体查询业务数据。每个智能体对应一个问数场景，单独交付与维护。

AI 智写 · 报告编排

2026.08 · AI 体验设计 · 开发中

AI 智写是观远数据分析产品中的 AI 报告功能。本项目以配置一次、按期自动生成为核心，重构报告的配置体验：将按系统运行逻辑设计的配置流程，转化为业务用户能够独立完成的任务流程。
