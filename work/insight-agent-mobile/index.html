项目背景

洞察 Agent 是企业 BI 平台中的深度分析智能体。业务人员以一句话提出经营问题，智能体自行查阅多张仪表板，数分钟后交付结论或分析报告。本项目设计的是提问者使用的对话界面。

项目快照

构建从问题发起、分析执行到结果阅读与持续追问的完整 App 体验，让用户容易开始分析、理解分析进展，并能依据结果进一步探索。

  • 分析前如何帮助用户把模糊的业务疑问，转化为可执行的分析任务？
  • 分析中如何让动态、复杂的分析过程变得清晰可理解？
  • 分析后如何把大量分析信息组织成有依据、可继续探索的结论？

设计已上线，以下设计保留在上线版本中：

  • 提问前身份区、专家前缀与报告类型标签
  • 思考过程过程区与收起后的完成行
  • 交付回答归属与报告卡
  • 回访顶栏切换与历史对话

项目目标

用户目标

在一个 App 内，通过自然语言提出复杂经营问题，快速了解问题原因，并通过持续追问获得支持业务判断的分析结论。

业务目标

降低复杂经营分析的使用门槛与人工成本，让更多业务人员能够利用企业数据开展分析，提高经营问题的响应与决策效率。

使用者

智能体由配置者在后台搭建，由提问者在对话中使用。配置者为智能体撰写描述，设定分析专家与回答形态；提问者按问题类型委托分析。本项目设计提问者一侧的对话界面。

配置者

数据生产者 · 在后台搭建智能体

  • 撰写智能体描述
  • 设定分析专家
  • 设定回答形态

智能体

对话中可见的部分

  • 分析专家
  • 文本或报告
交付

提问者

业务人员 · 本项目设计范围

  • 开放的归因问题

  • 事实查询

系统

产品架构

智能体的工作分布在四层中，提问者能直接看到的只有最上面的应用层。意图识别、任务规划、取数与报告生成都发生在下面三层；界面呈现什么、呈现到什么程度，决定了用户能否跟上一次分析。结论所依据的仪表板与卡片，可以在对话中溯源。

设计策略

运行信息的分层呈现

用户只看得到应用层，其余三层的运行产出要经过取舍才进入对话。设计按信息对判断的帮助程度分级，决定每类信息是否呈现、何时呈现。

设计过程

A · 提问前

提问前：明确智能体用途，找到提问起点

平台提供多个智能体，用户选中后，需要先了解它能做什么、可以怎么问。因此，界面通过身份区说明用途、推荐问题引导提问、分析专家提供预设的分析方式，帮助用户开始一次分析。

→

  1. 头像、名称与描述

    先说明“我能帮你什么”

    使用配置的身份信息说明智能体用途，移除无配置依据的问候与口号，让用户形成一致的能力预期。

  2. 可试着问我与推荐问题

    给用户一个可以直接开始的问题

    在用途说明之后提供推荐问题，让用户可以从具体示例发起对话，减少从零组织问题的负担。

  3. 输入框上方的分析专家入口

    让分析方式可以选择

    通过分析专家入口提供预设的分析技能，让用户在发起任务前选择本次采用的分析方式。

A · 分析专家

让选择结果留在提问现场

选中的专家名以行内前缀显示在输入框中，用户在组织问题时仍能确认本次分析方式，无需重新打开面板查看。

  • 部分专家带预设提问选中这类专家时，输入框会同时填入一条固定的推荐提问，用户可以直接发送，也可以在此基础上修改。

  1. 1点开分析专家入口

  2. 2在面板中选择一位分析专家

  3. 3专家名作为前缀留在输入框里

B · 运行中

只展开正在进行的一步

分析要走几步无法预知。已完成的步骤收为标签，每多一步只增加一行高度。

  1. 1意图识别中，自动展开

  2. 2识别完成，打勾收起

  3. 3深度思考收为标签

  4. 4再次思考，标签依次排开

B · 思考过程

意图与所选专家

意图识别展开理解结果，回答下方注明由哪位专家给出。

B · 思考过程

执行步骤与所查仪表板

洞察分析展开后列出所查页面与筛选条件，点按页面可上滑查看计算详情。

  1. 1点按所查页面

  2. 2上滑查看计算详情

B · 完成后

默认收起，支持回看分析过程

分析结束后，过程收为一行，让回答靠前；需要核查时逐层展开，不离开当前对话。

  1. 1收为一行，标明总用时

  2. 2展开后按阶段回看

  3. 3点开深度思考，查看分析计划

C · 交付

结论在前，报告以卡片交付

完成后先给两行结论，完整内容收进报告卡；中途停止则不生成回答。

  1. 1结论两行，点卡片看报告

  2. 2中途停止，不生成回答

  3. 3标出取数缺口

C · 报告

报告单独成页，依据可以追溯

点报告卡进入报告页；正文里的圆形角标对应一条生成依据，点开上滑查看所用数据。

  1. 1报告单独成页

  2. 2点角标，上滑看依据

D · 回访

会话从属于智能体

切换智能体在顶栏完成，左侧抽屉只列当前智能体的历史对话。

  1. 1顶栏显示当前智能体

  2. 2点切换，整列选择

  3. 3抽屉按时间列出历史

  4. 4标出仍在分析的会话

D · 追问

多轮追问，专家按问题匹配

在同一对话里继续追问；每轮按问题自动匹配分析专家，需要时也可以手动选择或更换。

  1. 1继续输入追问

  2. 2自动匹配专家回答

需要固定专家时，手动选择或更换
