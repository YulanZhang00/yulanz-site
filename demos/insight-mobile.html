移动端消费方案

单列消息流为主轴：过程压缩为一行状态、报告两段式消费（卡片 → 全屏阅读页）、hover 交互全部改为点击 + 底部 sheet，并把后端已返回的专家建议（suggestedNextExperts）从纯文字激活为可点击 chip。以下均可点击体验。

点一条推荐问题发起提问，观察过程一行状态（可点击展开三段步骤）与伪流式报告生成。
生成完成后点报告卡片进入全屏阅读页：移动版式 + 图表 + 表格横滚。
阅读页里点数字角标 ①——BI 卡片引用从 hover 预览改为底部 sheet。
返回会话，点@专家建议 chip（数据来自现有 suggestedNextExperts 字段）或直接输入，体验 text 类型回答与二次追问。
左上角 ☰ 打开历史会话抽屉；输入栏 @专家 打开专家底部 sheet。

对应现状约束的设计决策：消息类型仅 text / report 两种；生成期间输入禁用（现无停止接口）；过程数据来自 trace 三段解析；图表走 ChartRender(isMobile) 现成链路；报告在移动端定位为只读消费。所有交互均基于现有接口与返回字段，不含需要后端新增的功能。
